# 来源条款与目标复核协议

这是原文可核对性协议，不是额外业务事实或预期答案。describe_change登记真实变化后，程序把你已引用的新规则（删除用旧规则）拆成changes.obligations。条款保留真实原文和编号；表格/正文相同业务仍是一个Change，多个来源见证不增加业务变化数量。

sourceProgress.missingSourceClauses列出本轮实际变化中尚未被任何Change真实引用解释的条款；未读只给refId，已读给原句。一个段落登记过C编号不等于所有变化句子已经解释。遗漏时修订相应Change的before/after引用，保留其真实业务对象；同一业务的条件、定义和例外合并到同一Change，不为每条句子创建重复业务变化。独立业务可以分别登记并覆盖对应原句。来源引用未闭合不能完成或确认，不能用summary提到一句替代真实引用。

原文增删和业务变化分开：少写一个背景说明或换一种自然说法，不自动代表取消功能/角色或改变规则。先对照前后真实语义；同一规则的措辞/背景可以合并引用，纯文字变化登记editorial，确实无法判断才提出具体问题。只为引用覆盖创建虚假的独立业务变化会导致错误传播。工具错误给出的allowedValues/requiredFields是核心真实参数约束，直接使用它们，不轮流猜英文类型；inline relation说明的是目标如何承载规则，不是对差异正误的判断。

保留完整条件句：同一句里的“前提→即使例外→仍然禁止”等不能拆成独立名词。一个条款含定义及未构成动作的情形时，这两侧都要实际核对，不能只检查肯定侧。程序以句号/分号形成原文检查单元，仍由你识别其中的具体业务含义。

判断和修订前，逐条区分动作/角色、触发前提、定义、例外、尚未构成该动作的情形、保留边界；不能只记主动作。结合该目标的真实用途决定传播范围：完整操作/验收要核对实际规则各侧，概要允许简述，明确精选不强行扩展。未修改的既有边界也要保留。程序列出了原文条款，并没有替你断言目标应改；范围或含义不明时给具体问题。

review_document的checks逐条使用真实obligationId、该条真实source.quote、目标refId、outcome和targetWitness。不要一个笼统长引用替代所有条件。targetWitness.mode=present，quote必须是本目标实际现有文本或focus.preview的合并候选文本中的连续原句；该预览只是复核对象，不是原文证据、不能作为补丁定位锚点。用候选里的文字核对正反条件是否都保留；找不到定义/例外的目标见证时先修补提案，不能仅在reason声称已完成。

条款协议复核时通常只填memberId及checks中的changeId、obligationId、targetRefIds、outcome、targetWitness、reason；省source、顶层evidenceIds和proposalIds，让执行器从真实条款、已读取正文及实际草案绑定。显式提供的source/evidence不被覆盖，仍须准确。source只能是来源条款，不能填目标用途文字；目标用途只放targetWitness并说明不传播的理由。检查未知字段和JSON括号，不要为重复抄写编号增长嵌套参数。

每次复核提交3–5条checks并使用mode=append。程序保存已经通过证据和草案校验的条款，并返回剩余项；不要每次重写整份长JSON。下一轮focus.clauseReview.validatedChecks提供仍有效的已存检查，只补剩余条款。同一指纹下全部来源条款和实际提案均覆盖后，append可自动完成文档复核；或用mode=finalize、checks=[]尝试汇总已存项。补丁/判断/底本变动使旧检查失效，必须重新核对。只存部分检查不放行提案、不写业务文档。

不传播的条款也逐项说明，并用该目标真实用途/精选范围等文本作targetWitness。unrelated处使用not_applicable，不以current声称已有规则。current用于兼容或已更新内容；patched绑定实际草案。来源被完整底本阻断可以unresolved，仍绑定本目标见证和真实底本证据。

删除条款允许targetWitness.mode=absent：quote引用被实际提案移除的目标旧表达，必须旧文存在、候选全篇已不存在；不是没有找到就当删除完毕。其他情况用present。所有条件、例外和边界都应有可核对的实际目标文本；语义相同可以不同措辞，不要求逐字抄来源。

同一条款在多个目标承载点重复时可给多项checks。必要提案应覆盖所有承担该规则的位置。程序错误反馈会给遗漏条款或实际目标文本；按真实反馈补齐或修正，不猜新编号，不为应付门禁伪造结论。保持原权限、版本、预算与确认机制。
