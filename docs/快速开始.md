# 快速开始

本分支使用两篇单段合成资料，验证跨任务的已确认关系复用。建议在独立目录克隆，以免混用主工作台的资料库。

## 安装与模型配置

使用 Node.js 24，在本分支目录执行 `npm install --ignore-scripts`。将 `.env.example` 复制为 `.env`，自行配置模型 API key，再执行 `npm start`。

打开 <http://127.0.0.1:3084/>。未配置 key 时可以编辑和查看版本；真实检查需要配置完成。初始数据见 [`examples/confirmed-relation-documents.json`](../examples/confirmed-relation-documents.json)。

## 两轮操作

首次将费用规则中的300改为400，勾选操作指南并检查，展开依据后确认正确建议。确认完成后，目标保存为400，关系与来源检查点保存在SQLite。

重启服务后，将来源400改回300，用工具栏“检查本次修改”继续检查。编辑器旁的改动标记仍可能按首次导入基线显示，后台复用比较以已确认的400检查点为准。

确认第二次建议后刷新核对。撤销会恢复该批目标修订、保留来源变化，并使关系失效；旧建议需要重新检查。

## 窗口与记录

- 右上角×关闭窗口和停靠条，记录继续保留。
- “收起”折叠窗口，便于继续处理。
- 部分确认后可继续处理，也可关闭后从修订记录重新打开。
- 全部处理完且没有剩余事项时自动关闭。

## 离线检查与构建

```powershell
npm run test:relations
npm run build:ui
```

离线测试验证协议与保护行为，不代表真实模型语义准确率。
