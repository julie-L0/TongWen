# 验证与边界

本分支只报告两篇单段资料的关系复用实验。完整长文与任意资料的正确率没有由该实验验证。

## 真实模型结果

原实验完成首次发现、确认后复用和相同输入冷对照，合计14请求、98,698输入token和2,760输出token，均有提供商回执。来源检查点、热冷完整输入、正确目标、保存刷新与撤销等20项实机核对通过。

| 路径 | 请求 | 输入 token | 输出 token | 耗时 |
| --- | ---: | ---: | ---: | ---: |
| 首次发现 | 6 | 44,482 | 1,037 | 15.901秒 |
| 确认后复用 | 1 | 1,355 | 547 | 4.812秒 |
| 同输入冷对照 | 7 | 52,861 | 1,176 | 18.242秒 |

[原始结果](verification/relation-results.json)保留原验证身份。单次耗时也受网络与模型响应影响，不能承诺固定倍率。

## 适用条件

快速复用只支持两篇各一个正文段落的同步文档，且来源仅发生数值变化。存在额外正文、底本、历史、上下文变化或目标独立修改时，继续完整调查。关系只在人工确认合并后保存，模型单独判断不会成为已确认关系。

真实模型仍需要核对本次条件与目标见证。资料变化、取消、迟到响应、失败的复核和撤销均有保护；这些保护不替代独立语义验收。
